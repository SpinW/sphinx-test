Citing SpinW
============

How to cite SpinW
-----------------

Please cite the following paper if you use SpinW:

   S. Toth and B. Lake. **Linear spin wave theory for single-Q incommensurate
   magnetic structures**. *J. Phys.: Condens. Matter* **27**, 166002 (2015).
   `DOI: 10.1088/0953-8984/27/16/166002
   <https://doi.org/10.1088/0953-8984/27/16/166002>`_
