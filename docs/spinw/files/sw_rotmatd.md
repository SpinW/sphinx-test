# sw_rotmatd

## Syntax
  
`R = sw_rotmatd(rotAxis,rotAngle)`
 
## Description
  
`R = sw_rotmatd(rotAxis,rotAngle)` produces the `R` rotation matrix, for
identically to [sw_rotmat](#sw-rotmat), except that here the unit of `rotAngle` is
°.
