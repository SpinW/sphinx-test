# swfunc.Contents

The library contains basic mathematical functions that can be used by
SpinW for defining instrumental resolution function, etc.

## Files

- [swfunc.gauss](#swfunc-gauss) normalized Gaussian function
- [swfunc.gaussfwhm](#swfunc-gaussfwhm) normalized Gaussian function
- [swfunc.lorfwhm](#swfunc-lorfwhm) normalized Lorentzian function
- [swfunc.pvoigt](#swfunc-pvoigt) pseudovoigt function
- [swfunc.voigtfwhm](#swfunc-voigtfwhm) normalized voigt function
