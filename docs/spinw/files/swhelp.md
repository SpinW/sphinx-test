# swhelp

## Syntax
 
`swhelp(funName)`
 
## Description
 
`swhelp(funName)` shows the help on the given function name,
method, property name. Works the same way as the Matlab built-in
[help](https://www.mathworks.com/help/matlab/ref/help.html) command.
